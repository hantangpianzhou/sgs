# 三国杀皮肤原画素材库（sgs_norm）

《三国杀》官方皮肤原画 / 动态皮肤 / 官方壁纸个人收藏库，归一化整理版。
素材多源采集（百度贴吧绘影堂、B站 WIKI / 专栏壁纸等），本地浏览器画廊离线浏览。

## 使用方式

1. **浏览全库**：双击打开 `sgs_norm/index.html`
   - 搜索框 1：按图片名全局搜索（跨文件夹）
   - 搜索框 2：按文件夹 / 标签过滤
   - 点击卡片进入 Lightbox（←/→ 翻页，Esc 关闭，循环浏览）
   - 滚动时自动高亮当前文件夹标签
2. **处理未分类**：双击打开 `sgs_norm/未分类预览.html`
   - 按帖子分组看图，逐张填「归属武将」或选处置（留档 / 剔除 / 同图重复）
   - 标记存 localStorage，关闭浏览器不丢
   - 点「导出标记结果」生成 JSON，交归位脚本执行

两页均为单文件 HTML，图片相对路径引用本地文件，**离线可用**，无需服务器。

## 收录口径

- 收：官方 logo / 官网 / 版权、画师签名、二创与 AI 同人（单独标注）
- 不收：贴吧吧名标识、二传水印图、带游戏 UI / 版权栏 / 登录界面 / 文章卡片的截图
- AI 图必须显式标注：文件名 `[AI]` 前缀（官方疑似 `[AI疑]`），已确认 AI 的集中隔离存放
- 同图重复以 MD5 比对确认，互标注识
- 原始采集图（`sgs/` 目录，归一化前）保留不动，主库只存归一后副本
